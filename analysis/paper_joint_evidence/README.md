# 全局梯度改写的论文实验

## 14 个开发电路

固定预算联合 Adam 改善了 4/14 个原图，其中 3 个也比零编辑回放快。相对直接原图，交付延迟的几何平均降低 0.81%；相对一次原生 ABC Rewrite（B）则高 8.74%。逐电路与所有已提交贪心及随机方法中最快的结果比较，Adam 为 2 胜、5 平、7 负。这个逐电路最快对照是事后汇总，不能当成一个可线上部署的方法。

逐轮按全局边际梯度选合法编辑块的对照同样改善 4/14 个原图，几何平均改善 5.86%，相对 B 高 3.21%。它使一个原本慢于 B 的设计反超 B。纯局部贪心改善 6/14 个原图，几何平均改善 3.51%，相对 B 高 5.78%。这些分母包含回退与持平。两种全局梯度方法的所有交付均通过 CEC，交付面积几何平均变化分别为 +0.50% 和 +0.53%。

## 论文中可区分的三个案例

- **c5315 展示跨区域组合的真实收益。** 11 个单区域中最快为 450.18 ps，联合 16 编辑为 428.28 ps。去掉一个区域后还可达到 419.11 ps，属于额外真实测量。正式提交的 428.28 ps 对应面积增加 8.05%。去掉 LiteCut 修正的独立算法在此设计达到 420.90 ps。
- **cabac_ucontext 展示全局边际选块找到了高价值编辑。** 原图 14819.46 ps，B 为 14607.64 ps，选块后的 10 编辑为 7238.77 ps，面积增加 0.27%。原始入口和独立回放均复现。单个入选编辑就可达到 6020.89 ps。将这项收益归给逐轮边际选块，不能归给在该设计上回退原图的 Adam。
- **intra_pred_PE 展示 LiteCut 的作用与剩余排序误差。** 有、无 LiteCut 修正的 Adam 分别达到 1330.87 和 1366.60 ps。全局边际贪心达到 1332.82 ps。16 个单编辑中实测最快为 1278.87 ps。1400 ps 附近的几个结果用于比较不同提交方案，离线最好值单列。

## 实现与复现

当前可从同一个原始 AIG 入口分别运行 `--method gradient` 和 `--method global_marginal`。前者以软选择和 Adam 联合优化后投影，后者在当前组合周围计算全局方向导数，分块加入并由代理验收。二者都限制离散评估和最终真实提案预算。全局时序使用 ABC 映射的局部模板、Liberty 门弧、负载和 slew。LiteCut 在候选边界按局部延迟比率调整驱动项。最终结论使用真实冻结 ABC 的映射、CEC 和验收结果。

自适应编辑数和逐 PO 基线校准已作为可切换实验实现。四电路配对实测没有改善交付延迟，保留固定规模的原始默认配置。CPU/CUDA 同机原始入口在两个小样例上分别加速 1.13× 和 1.46×；大电路模板解析的 CPU 优化带来独立的全流程提速。[耗时与显存](RUNTIME.md) · [实验协议](PROTOCOL.md) · [异常与口径](REPRODUCTION.md) · [数据源和作业清单](sources.json)
