# 复现与测量口径

运行入口是 `scripts/load_rewrite.py`。原始 AIG、候选枚举和验证、Student 推理、两次 ABC 模板映射、PyTorch 全局传播与搜索，以及交付前的真实 ABC 验收都计入原始入口的墙钟。保持冻结的库、工具、输入和种子。用 `--alpha 0.5 --steps 8 --max-edits 16 --method gradient --mode delay` 复现默认方法。保持同一预算与输入，改为 `--method global_marginal` 可独立运行逐轮重算全局方向导数的选块对照；`--alpha 0` 从原始入口跳过 Student。`--adaptive-sizes` 与 `--anchor-outputs` 是配对实验开关。面积上限敏感性表只对已测提案施加交付门槛。

## 表格中的实验单位

- `raw_ps` 是方法自行提交的提案通过 CEC 后在冻结 ABC 上得到的 critical delay；选空时使用直接原图。提案无效保留失败记录。交付值遵循真实延迟验收。表中 `noop_ps` 单列同一回放路径序列化零编辑 AIG 后的真实结果。
- 同预算选优只允许每个方法提交一个提案。各轨迹的八个代理槽包括起始零编辑。全局边际贪心在没有可行改进时可提前停止；局部贪心本身不需代理打分。真实映射离线最优用于区分排序与候选生成的损失。相同向量共用其独立测量，重复搜索步保留在 CSV。
- 不同方法间取最优所形成的列需要事后知道各方法的真实结果。每个方法的正式性能用自己的选择计算。开发宽表分别列出所有贪心或随机对照的最低交付延迟，以及排除全局边际梯度贪心后、完全无梯度方法的最低值。逐电路 `area_pct` 和 `delivered_vs_b_pct` 的符号按交付值除以基准再减一，负值分别表示面积减小或延迟降低。
- `critical_po` 是从 0 起算的输出接口位置。同一个 PO 及同一极性的 rise/fall 可跨网络对齐。原图 AIG 根、映射器与门级网表的内部节点各自编号。扇入锥跨网表对比固定 PI 位置与 PO 顺序，并保留门类型和 Liberty 输入引脚顺序。
- CPU/CUDA 小电路端到端计时使用新进程、同节点和单个 PyTorch CPU 线程，各两次；候选枚举与回放都用原生 GPU 工具。显存列为父进程 PyTorch 分配器峰值，主机内存分列父进程与子进程的最大 RSS。单独的固定权重前反向实验同步 CUDA，记录两种输入权重下的数值、梯度差及耗时。改写排序相同与梯度浮点完全相等是两项独立核验。
- 外部验证名单按输入身份和规模冻结。14 个开发电路与 24 个外部电路各自汇总。案例拆解的额外真实映射不计入正式方法的选优预算。

## 外部验证的复跑差异

两份外部作业 66213、66214 使用同一提交 `54fcbc27` 和相同冻结名单。24 个设计都完成了原始 AIG 入口、ABC Rewrite、直接原图、零编辑回放和在已准备输入上的八种选择。汇总作业 66216 读取两份完整清单并校验交付哈希、CEC 和输入身份。[运行来源和命令](validation_sources.json)

固定种子的原始入口与同候选的 Adam 对照在 22/24 个设计交付相同 AIG。对 `unreg`，两个入口的交付延迟分别为 45.884655、44.5675926 ps；对 `mlp4` 为 193.367493、186.167511 ps。两对记录的零编辑代理评分一致，各自在第一次非零选择已使用不同编辑。两份模板森林 AIG 字节一致；初始与面积恢复 Verilog 逐行只有文件注释和模块名中的运行路径等头部文本不同。记录没有唯一确定首次梯度选择分歧的数值原因。主结果保留原始入口；有无 LiteCut 消融另取相同已准备输入的两臂，不在二次结果中择优。

## 运行记录中的异常

作业 66187 在 `systemcaes_comb` 复现历史顺序的断言处退出。其前两个电路的选择、冻结轨迹及离线测量已保存；第三个电路重新使用该作业冻结的全部选择并独立测量。作业 66195 用原始版本的时序内核，在历史入选步上按同一 logits 差值给历史的 16 个身份排序，测量了完整嵌套子集。历史第 2 步与复跑相差一个编辑，原始执行时未存当步 logits，重建顺序的历史一致性无法证明。16 编辑完整回放复现历史真实延迟。

作业 66191 的实验性逐输出偏移量被同名的组索引覆盖，连无校准对照的代理分数都失真。该作业所有数字都已排除。修复后在 66198 重新冻结和测量四个实验臂。六项针对原始端口解析与输出校准的回归检查通过，新增全局边际贪心对照后七项针对性检查通过。CPU 全套初检 66193 的一项历史测试依赖原生 CUDA 库；在 66195 配置实际库和 GPU 后，全套 231 项完成，19 项按环境条件跳过，0 项失败。加入转义端口与边际选择器回归后，在 66210 再次运行全套，共 233 项，214 项通过、19 项按条件跳过。

验证清单审计的初次作业 66190 无法从计算节点读取登录节点的历史路径。随后把 905 个文件校验并暂存到共享数据目录。66192 仅为候选清单探索，正式名单来自 66194，在任何新电路的延迟评估之前冻结。锥结构初检 66197 暴露出 ABC 对转义端口名附尾空格的情况。清理 Verilog 分隔空格并增加回归后，66199 重新验证真实第 663 号 PO 的映射锥。
