# Stage A 实验结果汇总表（GPU `rw4b` vs CPU `4B` 与 ABC 工业基线）

> **说明**：本文档汇总 Stage A 全部经过 Slurm + 真实 ABC ASAP7 工艺库映射（`map; stime`）与等价性校验（`cec -n`）验证的实验数据，所有数字均直接来自 `/data/wushangge/CULS_LiteCut/runs/` 下的原始运行日志与 `summary.json`。
> - **评测口径**：ASAP7 `delay_ps` 几何均值比值（`< 1.0` 越低越好）、映射后 `area` 几何均值比值、`ADP = Delay × Area`（面积-延时乘积，综合性价比指标，越低越好）。
> - **硬件环境**：GPU 节点 `eda`（NVIDIA GeForce RTX 4090 24GB，CUDA 11.8，GCC 11.4）；CPU 参考版运行于同集群 CPU 节点。
> - **严格盲测红线**：24 电路外部盲测集（`panel.json`）全程未读取、未调参、未评测。
