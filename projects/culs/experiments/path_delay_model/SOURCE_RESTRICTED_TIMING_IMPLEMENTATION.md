# Source-restricted ABC MIO timing implementation

The independent command `print_pair_delay [-tv] <PO> <PI>` runs on an ABC mapped logic network. It initializes the specified CI rise/fall arrival to 0 and all other CIs to `-ABC_INFINITY`, maintains a separate reachability bit per mapped object, and calls ABC's original `Abc_NodeDelayTraceArrival` for each reachable gate in DFS order. Source restriction changes only PI initialization/skip of unreachable gates. The MIO pin phase, rise/fall delay lookup, bar-buffer handling, and max recurrence are the original `print_delay` semantics. It returns `NA` with `reachable=0` when the target cannot be reached. `-t` prints a source-rooted critical transition trace with gate, pin, arc delay and arrival; `-v` independently calls the original all-PI and single-source timing engine for upper-bound/consistency checks. `PAIR_RESULT`, `PAIR_CHECK` and `PAIR_TRACE` are machine-readable and use `%.9g` on float32 ps values. `%.9g` exposes the stored float rather than increasing its precision.

Every query was checked against its all-PI PO arrival and against `Abc_NtkDelayTrace` with single-source CI seeds. All 32 saved Gate3B PI/PO pairs passed, and the requested `pi03→po11` trace starts at `pi03` with per-arc recurrence. The 82 checked c1355 combinations all happened to be reachable, so [the disconnected two-cone fixture](disconnected_pairs.blif) verifies that a truly unreachable pair returns `reachable=0`, `NA`; the connected control passes.

The corrected pilot deterministically selected 16 entries across R6/R9/R24/R37/R38 from the existing 67 single-candidate calibration rows by LiteCut-delta quantiles (R36 had no eligible candidate). Each existing AIG's SHA and replay trace identity/status were verified, CEC was rerun, and a new independent `read; map; topo; stime; print_pair_delay -v po11 pi03` measurement was made. No replay chain, partition change, LiteCut change, or rewrite-core change was made. Logs and manifests reside under `/data/wushangge/runs/CULS-source-pair-20260930-qU1wxi/output/`; small results are in [results](results/).

This defines a **source-restricted PI/PO endpoint-pair maximum mapped delay**, not delay along the old original-AIG node path and not a sensitized delay. Mapped node IDs are used only within each mapped run; correspondence across different mapped designs is not assumed.
