# ABC 原生指令的全局对照（step3_v3 的 C 部分）

## 范围

- 这是**全局基线**，不参与候选选择比较，也不做映射延迟。
- 每个命令都从**原 AIG 重新 `read_aiger`**（不 `strash`），执行后 `write_aiger` 输出，再单独做 CEC。
- `resyn2` 和 `compress2` 不依赖别名，按 ABC `abc.rc` 的定义展开成全名命令（本机构建的 ABC 没有 `abc.rc`，
  短名 `b/rw/rf/rwz/rfz` 不可用）。展开结果见下表。
- CEC 用 `-n`（忽略 PI 名字）：`write_aiger` 会丢掉原图的 PI 符号，名称不同的同一网络仍必须布尔等价。

| 命令 | 实际执行序列 |
|---|---|
| balance | `balance` |
| rewrite | `rewrite` |
| rewrite -l | `rewrite -l` |
| refactor | `refactor` |
| resub | `resub` |
| resyn2（展开） | `balance; rewrite; refactor; balance; rewrite; rewrite -z; balance; refactor -z; rewrite -z; balance` |
| compress2（展开） | `balance -l; rewrite -l; refactor -l; balance -l; rewrite -l; rewrite -z -l; balance -l; refactor -z -l; rewrite -z -l; balance -l` |

展开映射：`b`→`balance`，`rw`→`rewrite`，`rf`→`refactor`，`rwz`→`rewrite -z`，`rfz`→`refactor -z`。

## 读法与限制

- `balance` 只做结构平衡，`resub` 常常不改变层数，`resyn2`/`compress2` 在本批电路上通常给出最大的层数下降。
- `rewrite -l` 在 10 个电路上反而让全局 D 升高（合计 +18），`compress2` 也有 9 个；层数驱动的局部替换
  不等于全局变短，这一点和 (A) 的结论一致。
- TNS 是**未映射**的 AIG 输出层数超出阈值的和，只能说明结构层面的近临界输出压下去了多少；真实延迟仍要映射，
  本步骤不做。
- 这些是全局命令的基线，与 (A) 的“cut 内部选择”不是同一层次的比较，不能互相替代。

## 与计划不一致的地方

1. **`compress2` / `resyn2` 用全名展开**：本机 ABC 没有 `abc.rc`，短别名不可用；展开与 `abc.rc` 的定义逐条对应，
   语义不变，但命令串与别名写法不同。
2. **CEC 忽略 PI 名字**：`write_aiger` 不保留原图符号，带名字的 CEC 会在所有有符号电路上失败；改为 `cec -n`，
   布尔等价检查不变。
3. 没有做映射延迟、没有安装候选、没有联合替换。
