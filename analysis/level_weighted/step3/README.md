# Step 3：五种叶子权重在 ABC 导出候选上的选择比较

## 覆盖范围（先读这一节）

- 只覆盖 **ABC rewrite 会评估的恰好 4 个叶子的 cut**。ABC 在 `rwrEva.c` 里对 `pCut->nLeaves < 4`
  直接 `continue`，所以叶子不足 4 个的 cut（第 2 步记的 127,543 个，占非平凡 cut 的 41.3%）不在这份
  比较里，一个候选都没有被估算。
- 选择只发生在**每个 cut 内部**：对同一个 `(node, cut)` 的候选按 J 取最小。**不比较不同 cut 之间**，
  也不产出"每个节点的最终候选"；同一节点的多个 cut 各自独立选。
- 没有安装任何候选、没有重新枚举 cut、没有做映射、没有跑 ABC rewrite 的联合替换。整个步骤是纯 CPU
  的读表与重算：148,278 个决策、958,897 个候选，Slurm 作业 23 秒。
- cabac_ucontext 有 1 个节点（ABC 编号 12381，即第 1 步 root 9211）因扇出 >1000 被 ABC 跳过，它没有
  cut、没有候选，**被排除在决策集之外**；其余三个电路没有这种情况。

## 定义与实现

| 量 | 实现 |
|---|---|
| level、req | 用第 1 步的实现 `global_timing.level_weights.propagate_levels`，在**原 AIG** 上重算；`req` 覆盖所有 AND |
| d_orig(l) | 第 1 步的 `original_leaf_depths`：从 node 反推最长路，遇 cut 叶子即停；返回每个叶子的原层数 |
| slack_l | `req[node] - (level[l] + d_orig(l))`，用 **node 的 req**，不是叶子自身的节点 slack |
| J(c) | `Σ_l w_l · leaf_depths(c)[l]`；`leaf_depths[i]` 对应 `leaves[i]`，`-1` 表示该叶子未被用到，贡献 0 |
| 权重 | 不加权 `w=1`；硬权重：4 个叶子里 slack 最小者 `w=1`（并列都取 1），其余 0；软权重 `w=exp(-slack/τ)`，τ∈{0.5,1,2}，**不归一化** |
| J0 | 同一权重与 `d_orig` 作用在原结构上：`Σ w_l · d_orig(l)` |
| 选择 | 同一决策内 J 最小；并列依次比 `nodes_added`（self=1 的 `-1` 按 0）小者、`subgraph` 小者 |
| 编号 | `abc_and_id = aiger_and_id + PO 数`（4 个电路的偏移都等于各自 PO 数，已逐个断言） |

候选**不做任何过滤**：`accepted_by_default=0`、`self=1`、面积更差的候选都参与比较，`accepted_by_default`
只作为标签保留。

## 断言与不一致计数

所有断言都写在 `scripts/level_weight_selection.py` 里，违反即中止；只有任务要求"计数并列出、不中止"的
两项（自替换深度、bounded MFFC）继续执行。

| 电路 | cut 层数重建 | 候选数组顺序 | 自替换深度不一致 | bounded MFFC 不一致 |
|---|---:|---:|---:|---:|
| c1355 | 3,300 / 0 | 11,114 / 0 | 0 | 0 |
| c5315 | 5,276 / 0 | 18,701 / 0 | 0 | 0 |
| intra_pred_PE | 17,647 / 0 | 77,681 / 0 | 32 | 0 |
| cabac_ucontext | 122,055 / 0 | 851,401 / 0 | 44 | 0 |
| **合计** | **148,278 / 0** | **958,897 / 0** | **76** | **0** |


- **cut 层数重建**：对每个导出 cut，`max(level[l] + d_orig(l))` 必须等于 node 的 level；148,278
  个决策全部通过。
- **候选数组顺序**：按数组位置算的 `max(level[leaf_i] + leaf_depths[i])` 必须等于导出的 `root_level`；
  958,897 个候选全部通过。
- **bounded MFFC**：按 `rwrEva.c` 的做法（把 4 个叶子的扇出计数临时 +1，再做引用计数式解引用）在
  原图上重算，与导出的 `n_nodes_saved` **0 个不一致**。这也顺带说明这批导出确实是在未被改写的网络上
  产生的。
- **自替换深度**：76 个自替换候选的 `leaf_depths` 与 `d_orig` 不等，集中在
  19 个决策里（intra_pred_PE 8 个、cabac_ucontext 11 个），**模式全部是四个位置同时 +1**，且这些候选的
  `root_level` 也正好比原 level 高 1。也就是说：这些"自替换"图在 root 处多套了一层 AND。它们仍按原样
  参与选择（J 也高 1），只在这里登记，不做修正，也不中止。

关键一项：选中的候选里 **83.7%–89.6%** 是 ABC 默认会丢弃的（`accepted_by_default=0`），
而"让 root_level 严格降低"的候选里有 **77.0%–79.3%** 属于被丢弃的那一类。也就是说，
加权选择挑中的多数改进在 ABC 的默认规则下根本不会落地——这正是两套准则分歧的核心。

软权重按任务要求**不归一化**：slack 很大时 `exp(-slack/τ)` 下溢到 0，J 退化为 0，这类决策实际由并列

24.6%、19.1%；不加权与硬权重更高
（58.9%、52.1%），因为它们的 J 本来就是小整数。
