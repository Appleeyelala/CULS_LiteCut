# v3 冻结组合的纯排序评估

**建议把“仅全局残差”作为下一步排序研究的参考版本；当前四种代理均不足以证明能稳定选出真实最优组合。** 仅全局残差在真实可区分组合对上的准确率最高、平均选中 regret 最低、三种子表现相对稳定；端口＋全局残差的 Top-1 命中率最高，但出现更强的反向排序和更大的 regret。这两个结论应同时保留，不能宣称某一版本在所有指标上获胜。

本报告只重算已有 `work/joint-gradient-v3` 验证面板，源分支快照为 `9da83466686fb981c7fcbc6347720cdff9e76baa`。12 电路，每个 8 个已冻结非空合法组合，共 96 个唯一组合；fixed 使用原记录，ports/global/combined 各保留 20261117、20261118、20261119 三个种子。没有训练、模型推理、生成候选、修改模型或搜索器，也没有新增 ABC Mapping。

## 预先固定的评价规则

协议先于本轮统计提交，提交号 `2cd197e5`。预测与真实 Delay 都用 **0.001 ps 绝对容差，零相对容差**。升序排列后，以组内最小值为锚点，将跨度不超过容差的值归为一组；组内使用平均名次。这样得到传递的并列关系，避免“a≈b、b≈c、a不≈c”歧义。跨组的相邻值仍可能小于容差，所有指标均按同一组身份判断。容差是本轮的数值分辨率约定，不是重复 Mapping 噪声估计；没有扫描阈值或按结果调整。

这与旧 pilot 的随原图 Delay 缩放并量化的容差不同，因此本轮系数可能不同于旧摘要；旧文件保持原样。原预测字段来自 `train_joint_gradient_ports.py::evaluate` 的各 PO arrival 最大值，没有用 loss、结构时序分数或局部 Delay 代替。

- **Spearman**：两列平均名次的 Pearson 相关。**Kendall tau-b**：`(C−W)/sqrt((C+W+P)·(C+W+T))`，P 为仅预测并列，T 为仅真实并列，双方并列不进入分母。
- **Pairwise Accuracy**：每电路 `C/(C+W+P)`，真实并列不计入分母，预测并列不奖励半分。另提供仅有预测方向时的准确率，但不以它替代主指标。
- **预测并列比例**：预测并列对数 / 28，包含双方并列。不可区分组合数是处于大小≥2并列组中的组合数；另外保存 `8−预测组数`，避免混淆两种计数。
- **Top-1**：预测最小并列组中选冻结组合编号最小者，绝不看真实标签解并列。选中组合属于真实最小并列组即命中。另报在预测最小组内均匀解并列的期望命中与 regret，及最好/最坏 regret。
- **Regret**：选中组合真实 Delay 减去八组合中的最小原始真实 Delay；百分比以该最小值为分母。不把小差值强制清零。预先固定“接近最优”为 regret≤1%。最优仅限这八个组合，不是整个合法搜索域的最优。
- 单电路系数未定义时 CSV 留空（表示 undefined），不会写成测得的零。主汇总将其补零并标注，另列定义数和仅定义值均值；全部电路保留。Pairwise 若无真实可区分对则留空并计定义数；本数据每电路均有可区分对。
- 总体为先电路等权、再种子等权。固定模型只算一次；学习版本三个种子各占 1/3。所有排序都在同电路八组合内部完成，绝不混排不同电路的绝对 Delay。

学习端口的补零平均 ρ、τ 略高，**不能隐去这一点**。但它在 22/36 电路×种子上完全不能区分八组合，仅 14 个可定义系数的均值为 0.3346；高并列使主 Pairwise Accuracy 最低。不能凭这一个相关均值把它认定为最好的选择器。

Spearman 补零中位数依次为 **0、0、0.1916、0.1071**；Kendall 补零中位数为 **0、0、0.1429、0.0552**。仅全局残差虽有最佳 Pairwise Accuracy，也只比无并列随机方向的 50% 数学期望高约 4.9 个百分点。本轮没有独立测试或显著性证据，不能据此宣称稳定有效。

## 哪些电路能排序，哪些失败

全量逐电路名次、真实最优集合和选中组合见 [逐电路明细](PER_CIRCUIT_RANKINGS.md)，以下只是概括，未用于筛选样本。

- **固定结构端口**：ID1、158、168 全并列；ID5、75、770、179 的 ρ 为负。ID41 排序较好（ρ=0.7313），但真实最优本身有五个组合并列；ID421、58 也有正向关系，仍含大量预测并列。
- **学习端口**：ID58、75、1、158、168、179 三个种子始终全并列；ID44、5、770 还会随种子进入/离开全并列状态。较明确的正向信号集中在 ID421、41，不能扩展为全电路可靠。
- **仅全局残差**：ID421、58、44、158、41、168、179 三个种子均为正相关；ID5、75、1、770 均为负相关，ID68 符号不稳定。14/36 个电路×种子为负。ID1 三种子均 ρ≈−0.639、选编号7而真实最佳为2/3；ID75 可产生 12.657% regret。这是方向错误，不是仅绝对数值偏移。
- **端口＋全局残差**：ID421、158、770、41、68 三个种子均正相关；ID58、5、75、1、168 均负，ID44、179 符号变化。17/36 为负。ID75 三种子的 ρ 为 −0.626、−0.901、−0.826，强烈反向；ID179 第一个种子选编号2产生15.517% regret，另两种子选8仍有4.484%。

不存在任何一份电路×模型×种子记录具有完全一致的整体排序（ρ=1）。这不否定局部选中最佳的情况，但说明“消除了并列”与“学会了正确排序”是两个不同问题。特别是 global 与 combined 几乎都能区分八组合，却仍有大量方向错误；本分析不能单独证明这些错误来自哪一个网络模块或梯度环节。

## 能否选到最优或接近最优

可以在**部分电路**中做到：combined 的精确命中最多，为12/36；global 为10/36。按预定的1%域内 regret，global 为22/36，combined为21/36。global 的平均 regret 较低，但最大仍为12.657%，不是稳定接近最优。

固定端口的 regret≤1% 比例反而达到8/12，说明“选得近”不能单独证明排序强：例如 ID5 的固定端口 ρ<0，却只有0.032% regret；ID1 固定端口完全并列，选编号1仍只有0.987% regret。具体组合域的真实差距、真实最优并列数和解并列规则都会影响该指标。逐电路表同时展示八组合中有多少本来就处于最优1%以内，以免把较平坦的候选域当作选择器的功劳。

本轮结论不依赖代理绝对误差，但也没有证明“绝对预测不准仍能可靠指导优化”。当前数据只支持：**global 提供较好的弱排序信号，combined 更容易命中域内最优但风险和种子波动较大，ports 的排序分辨力严重不足。** 后续可优先以 global 为排序参考，保留 combined 作为 Top-1 对照；任何推广都需要受控标签和新的独立冻结组合验证，本轮不实施这些后续工作。

## 证据边界与复现

这是既有验证集的再分析，不是新测试集。学习时已使用该验证集选择 checkpoint，三个种子共享相同真实标签；不能把36当作36个独立电路，也不能据此估计未知电路的泛化。12个电路不足以支持强统计优越性结论。

原 v3 serialized no-op 审计发现19/24电路仅序列化后 Mapping Delay 就发生变化，最大相对漂移32.2907%。本轮在同一电路的八个已测非空组合之间排序，不直接用原图与 no-op 的差值，但**不会消除原标签中的输入编码/Mapping 测量混杂**。不据此唯一归因于模型或 ABC 随机性。没有混用 `work/cut-timing-proxy` 或其他分支的 Mapping 标签；没有重测、改标签、回退或重新选组合。

只读计算源码为 `2cd197e5`，Slurm **66047，COMPLETED，退出码0**；7项数学与并列处理测试通过，包括对照 SciPy Spearman/tau-b。全部运行文件留在 `run_record.json` 指向的 `/data` 目录。原 v3 预测和实验记录未改动。
