# 评价体系与备选算法：文献记录

检索日期：2026-11-13。本文区分论文已报告内容、当前工程报告和面向本项目的建议；不是穷尽式文献综述，也不表示这些算法已经在本工程验证。

## 一、研究定位

项目以跨 MFFC 梯度联合选择与 GPU 并行为研究重点，追求 mapping 后 critical delay 与端到端 runtime 的良好权衡。不以精确的 local-to-global 预测作为独立主线，不要求每个电路的 delay 都胜过 ABC。

已有工程依据：`GRADIENT_OPTIMIZATION_STATUS.md`，尤其 §2、§5.2–5.3、§8.2、§9。当前是 Softmax/STE/Adam 加在线校准代理；主实验候选梯度使用 CPU float64，不能因候选枚举已有 GPU 就宣称完整 GPU 优化已完成。

### 必须记录的 CULS 更正

作者的 Updated Results 指出原 ABC patch build 没有默认启用编译优化，随后按标准 Makefile 重做基线。更正表中 GPU resyn2 的几何平均加速为 **26.4×**，而不是原文的 **45.9×**；节点数/levels 和 GPU 时间未变。[R1–R2]

因此，本项目需要核对 ABC/CULS 编译配置，并分别报告内核、算法以及端到端时间，不能直接沿用论文宣传数字。

## 三、本项目建议采用的评价体系（研究建议）

### 1. 主评价：真实 Delay–Runtime 权衡

固定输入、Liberty、ABC 版本和 timing 条件，统计 mapping 后 critical delay、area、总 wall-clock runtime。报告每个设计、按规模/来源分组及总体的归一化结果，保留失败与退化案例。

重点观察两个方向：相同时间下的最好已验证质量；达到预先定义质量所需的时间。质量容忍范围和面积口径须在最终测试前固定，不从结果反推阈值。尚未达到质量门槛的结果如实记为未达到。

当前 area_constraint 可作为主评估起点，但其 1.05 限制是现有配置，不代表已经由用户最终确认。joint 的 delay–area 分数独立汇报，不替代纯 delay 比较。

### 2. 梯度贡献：同时间 + 同预算 + 消融

在相同候选域、约束、初始化/反馈条件下，与随机、局部贪心及当前版本比较。请求数包含 warmup、失败、修复；额外记录实际 mapping 次数和缓存命中。只有真正完成验证的结果才能进入 best-so-far。

独立检查梯度提案的执行成功率、真实改善率、变化方向/排序质量及耗时；将最终结果来源分为直接提案、修复、warmup 与 no-op。预测误差只是诊断，不能代替优化收益，也不能由回归误差推导“离散梯度准确率”。

### 3. GPU 贡献：同算法 CPU/GPU 与端到端验证

保持工作量和算法语义可比，核对精度与 QoR。分开记录候选计算、LiteCut、代理/梯度、选择/冲突、replay、CEC、mapping/timing、初始化和传输等时间；并发阶段不能简单相加充当总时间。

单个电路内部的 MFFC 并行与多个 benchmark 并发分别评价。按图规模、DAG 深度、可并行区域/候选数量观察收益，报告内存/显存和不适合 GPU 的小设计。不能以 GPU 内核加速代替全流程加速。

### 4. 基线、重复性与贡献归属

比较原图 mapping、replay no-op、native ABC rewrite、LiteCut 贪心、同预算随机、当前 CPU/GPU 框架，以及适用的原生 CULS/GPU 流程。不同优化序列应说明工作量和计时差异，不冒充完全相同算法。

MFFC/GPU resynthesis 已有 CULS 工作；必须区分复用能力与新增的联合梯度/并行机制。开发集与最终评估分开，对同族变体分组并检查多随机种子；已用于调试的 905 设计不自动构成未见设计泛化证据。

## 四、备选算法清单：记录，不要求本轮实施

下列触发条件和迁移判断是本项目建议，不是论文已证明的 AIG 结论。

### A. Generalized and Optimal Straight-Through Estimators — AISTATS 2026

**论文内容：** 建立广义 STE 类，并在偏差约束下研究最低方差估计器，包含 one-hot categorical 变量；官方代码含 MVE、ST、ZGR 等。[R6]

**备用位置：** 候选选择的反向梯度估计器。

**考虑启用的条件：** 排除代理方向和可执行性等主要问题后，仍有证据表明 STE 估计偏差/不稳定限制优化。

**边界：** 论文研究随机类别变量的期望损失；当前工程的确定性 argmax 加静态冲突投影不能不加说明地视为同一问题。“Optimal”针对论文规定的偏差—方差准则，不保证 AIG 离散最优或更好 runtime。

**当前状态：** 高相关备选；已核实官方代码存在，未运行或验证移植。

### B. Categorical Reparameterization with Denoising Diffusion Models（ReDGE）— ICML 2026

**论文内容：** 为 categorical 分布提出扩散式软重参数化与梯度估计方法，实验覆盖潜变量模型和离散扩散的推理时引导；官方论文页提供代码。[R7]

**备用位置：** 类别选择的连续松弛/梯度估计。

**考虑启用的条件：** 类别选择持续难以探索或估计机制成为有证据的瓶颈，且允许额外实现和计算成本。

**边界：** 不是 AIG rewrite 算法，未证明能处理本项目的可执行性投影；也不是需要立即重训一个扩散模型的理由。

**当前状态：** 低于 A 的备选优先级；先记录，不主动引入复杂度。

### C. Quad-Gradient — DAC 2026；Differentiable Physical Optimization — ICCAD 2025

**论文内容：** 在合法的离散 sizing/buffering 修改中利用梯度安排更新；前者有 Top-K 和防振荡冻结机制，后者有资源约束下的分阶段离散更新。[R4–R5]

**备用位置：** 每轮改动的范围、合法离散动作选择和稳定性控制。

**考虑启用的条件：** 单次选择变化过多、运行时拒绝多、反复切换或修复开销成为主瓶颈。

**边界：** rewrite candidates 没有 drive-strength/Vth 的天然二维顺序，不能直接套用“四个方向”。只借鉴更新控制思想，必须保留候选兼容性与真实反馈验证。

**当前状态：** 与当前高失败率问题相关的策略参考，不要求立即替换 Softmax/STE/Adam。

### D. INSTA — DAC 2025

**论文/项目内容：** GPU 可微 STA，公开接口可反传并导出时序弧梯度。[R8]

**备用位置：** GPU 图传播与反向传播的工程参考，不是 Adam 替代品。

**考虑启用的条件：** profiling 证明当前图传播/反传是明显瓶颈。

**边界：** 依赖已有 timing graph，不会自动预测 AIG rewrite 后的 mapping；不要求将整个引擎接入。代码采用 NVIDIA Source Code License，复用前核对许可。

**当前状态：** 官方仓库已核实，未运行；只保留可借鉴的并行思路。

### 补充：AGD 与 GradMap

AGD（TODAES 2025）可作为 one-hot/STE 的已有方法参考；GradMap（ICCAD 2025）可作为 mapping、buffering、sizing 联合优化的相关工作。本次对两者主要核实公开摘要和出版记录，未据此宣称完整实验细节或复现实现。[R9–R10]

GradMap 摘要明确承认相对 ABC 的运行开销较高；“可 GPU 并行”不能直接解读为已取得低端到端 runtime。

## 五、使用备选的规则

先识别瓶颈，再决定替换部件；一次验证一个主要假设。现有方法表现不好，不自动说明 Adam/STE 有错；同样不能因算法来自新论文就默认更好。采用任何新方法后仍回到相同真实质量—时间评价，新增开销必须计入。
