# 新框架的限制与失效案例

本文件讨论新增系统。历史测量口径、标签更正和原始证据边界仍见 `docs/KNOWN_LIMITATIONS.md`，不回写旧实验以制造一致性。

## 研究结论

已实现并真实运行从AIG到联合选择、顺序rewrite、CEC、Liberty测量和反馈的闭环。这不等于代理模型已经准确，也不等于新方法优于基线。c1355不同开发版本/相同预算出现不同表现；四设计pilot中，梯度搜索、随机与独立region各有占优和失效的电路。不得选择性报告第一次改善。

当前标签都是固定ABC、固定ASAP7和相同mapping命令下的技术映射结果，没有布线寄生、物理布局或signoff STA。历史MIO、source-restricted pair和mapper mode0 arrival不能直接混作这些Liberty标签。

## 近似模型

LiteCut输出是局部abc_delay代理。全局模型把局部/结构相对变化通过端口Region DAG传播，以真实no-op端点锚定并反馈拟合。它没有精确模拟重映射后的cell cover、相位、负载/slew、pin重排或远距离高阶交互。基线锚定精确不是预测正确的证据。

候选仍受GPU正节点增益mask限制。静态冲突投影保守，运行时增益重算仍可能REVERTED；修复必须重新请求且占预算。STE不是离散真实目标的精确导数，投影不求全局最优。小预算可能被warmup与失败修复消耗，报告必须列出真正梯度提案的实际评估次数。

原始图的静态排除还不完全描述动态结构可行性。DSP保存trace中，root20035执行前的removable集合新增了初始另一region的节点20019，删除后使root20097的cut失效。组合被如实拒绝，未用部分安装的指标拟合。初始cut归属、运行时删除集合和新图MFFC是不同对象；细节及hash见[中间搜索审计](INTERIM_SEARCH_ANALYSIS.md)。最初44设计审计及后续97个成功设计的冻结审计中，直接梯度请求的完整通过率均不到一半，不能只分析已成功请求而隐去失败预算。

多路径目标覆盖Region DAG全部入口和全部PO，并保存实际critical/near-critical端点。没有对所有映射网表之间的逻辑路径建立身份对齐；关键PO集合变化不能自动写成某条唯一逻辑critical path切换。

可选observer已经为8设计的124份保存映射重构最大arrival链，并检查插桩不改变网表与测量。每个near-critical PO只输出一条最大链，不枚举所有并列链；采用ABC静态合并后的slew/load，不证明布尔可敏化性。源/端点集合发生变化也不足以确定原AIG中的唯一逻辑路径身份。其覆盖范围尚未达到全部905输入。

## 跨设计工程问题

- CULS支持最小化后的cut不一定是完整结构边界；cut叶子也可能逻辑相关。新验证保留原始PI/叶子函数做上下文CEC。未证明项明确排除并保留原始导出，不能把验证规模限制解释为功能错误。
- replay不保存原AIG符号名，CEC使用明确的PI/PO位置契约并先检查接口数量。全局测量仍按固定PO顺序比较。
- 已确认旧`WriteAig`多翻转一次常量0/1，导致含常量输出的no-op也不等价；修复后实际CPU序列化及GPU常量replay回归通过。旧错误输出保留，完整跨设计结果另行验证。
- 原始输入与no-op序列化的mapping结果可能不同，例如c5315和c7552。报告必须保留两者，不把全部差值归为候选优化。
- 大电路暴露了按cut重复构造region全集及独立region按候选重复逐项特征求和的开销。修复采用共享只读集合及保留顺序的批量累加；新旧成本和选择一致性必须通过实际保存案例检查。较快的选择过程不意味着代理预测更准确，也不替代超时设计的完整真实重验。
- 深DAG的默认arrival传播改为显式一阶反传，保存div校准及完整梯度轨迹与原实现精确一致；该算子不支持二阶求导，存储上界不包括框架其余数据。完整benchmark超时记录仍保留，不能用剖析通过替代真实E2E。
- `forgeEDA/ALU.aig`在修复版全量扫描的零rewrite阶段出现过原生SIGSEGV（返回码−11），当时没有输出trace/AIG。64340.5使用同一旧二进制和相同输入hash在GDB下未复现：6449条trace全部未选择、零rewrite，随后CEC与mapping通过。因此记录为`PASS_NOT_REPRODUCED`，不将原失败改成PASS。发现的构造函数CUDA调用未检查和未初始化输出变量已单独修正，但没有证据证明它就是该次崩溃的根因。
- 64340.7中的ALU和voter已使用新版工具完成完整比较；64341.4中的div在提高至3600 s限制后通过。原始失败仍保留，不作为旧版运行已通过或原崩溃根因已证明的证据。voter的未变化入口重复计算已由`0e1cbd9`缓存处理；64379核对4个保存设计的成本与完整请求完全相同，64340.8完成缓存版c1355真实回归。缓存版voter目前只有保存输入核对，不能冒称它又完成了一次完整E2E。
- 全量扫描的`forgeEDA/Division.aig`（index147）在native ABC rewrite的CEC阶段超过300 s限制。保存输入为38,773 AND、64 PI、14,205 PO；旧运行未取得证书，不是已证明不等价。64382复用原输入、保存的native AIG和同一ABC，原命令在延长限制后于306.23 s证明等价；自动分区版本仍在300 s超时。单独证明不替代完整benchmark，也不改变旧FAIL或用缺失的timing补数值。

## 测试与可复现性

程序矩阵区分语法、导入、CLI smoke、编译、命名功能测试和真实E2E。编译对象存在不证明每个函数运行过，`--help`成功不证明训练成功。历史脚本仍含固定输出路径；缺少DGL、DeepGate、einops、原训练数据或参数的入口明确FAIL/SKIP，未自动覆盖旧目录或重新训练。

输入、模型、库、工具、源码、随机种子和线程设置均需对齐才可复现。并发worker的墙钟时间受共享CPU/GPU影响，应同时报告每方法时间与完整Slurm时间；单种子和小预算对比不足以声称统计显著优势。尚未完成的全量、复现和回归项目以验收矩阵为准。

修复回归作为现有Slurm分配内的独立step运行，未新增GPU allocation，也未停止旧版分片。step与旧batch存在资源竞争；对应墙钟时间只用于诊断，不能当作独占资源的算法性能证据。原生ABC的AIG注释包含时间，文件字节hash可能不同；新增结构hash保留全部节点ID、fanin literal及PI/PO顺序，只排除名称和注释，不把布尔等价当作结构相同。
